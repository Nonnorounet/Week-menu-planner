# Menu Week - Android app

1. Create a new GitHub repository (private is fine) and upload everything in this folder
   (keep the .github folder).
2. Open the repo's Actions tab. The "Build APK" run starts automatically (or choose Run workflow).
3. When it turns green, open the run and download the MenuWeek-apk artifact (a zip). Unzip it to get app-debug.apk.
4. Copy the APK to your phone, open it, and allow "Install unknown apps" if asked.

Exports (PDF, Excel, CSV) are saved to your phone's Downloads folder.
To change the app, edit app/src/main/assets/index.html and push again.
